    How your data stays private

    1. Derive — your passphrase is stretched with PBKDF2-SHA-256 (600,000 iterations, per-vault salt) into a 256-bit key. The key is non-extractable and exists only in memory while unlocked.
    2. Encrypt — each entry is sealed with AES-256-GCM using a fresh random 96-bit IV. Titles, usernames, secrets and notes are all ciphertext.
    3. Bind — every ciphertext is authenticated against its entry id, so entries cannot be swapped or reordered unnoticed.
    4. Store locally — the encrypted vault lives in your browser's storage or in a file you export. Nobody else can read it: not us, not a provider — nobody.

    No telemetry, no network requests (this page's Content-Security-Policy blocks connect-src entirely), no accounts. Read the STRIDE threat model for the full analysis.
